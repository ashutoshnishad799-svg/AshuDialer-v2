# Name, logo and branding

The source code of Ashu Phone is free software under the GPL-3.0-or-later (see
`LICENSE` and `NOTICE`). **The branding is not part of that grant.**

The following are the property of Ashutosh Nishad and are **not** licensed for
reuse:

- the names **"Ashu Phone"**, **"Ashu Dialer"** and **"AshuPhone"**
- the launcher icons and the images in `app/src/main/res/drawable-nodpi/` and
  `app/src/main/res/mipmap-*`
- the Android package name **`com.ashudialer.app`**
- the official download page, update server and signing key

## If you fork or modify this app

You are welcome to. Please:

1. **Rename it** (a different app name and a different launcher icon).
2. **Change the package name** (`applicationId` and `namespace`) to your own.
3. **Use your own signing key.** Never try to publish under the official key.
4. **Use your own Firebase project.** Do not reuse `google-services.json` from
   this project, and do not point your app at this project's update server or
   backend.
5. **Say clearly that it is unofficial**, for example "based on Ashu Phone by
   Ashutosh Nishad", and keep the copyright notices required by `NOTICE`.

## What is not allowed

- Publishing a modified copy that uses the Ashu Phone name, icon or package
  name, or that could be mistaken for the official app.
- Distributing a rebuilt or repackaged APK as if it were the official release.
- Adding advertising, tracking, or malware to a copy that still carries this
  branding. Users trust the name; do not borrow it.

## The only official app

The official builds are the APK files attached to the Releases page of
https://github.com/ashutoshnishad799-svg/AshuDialer-v2, signed with the
developer's key. The app itself checks this: a copy signed with any other key
shows a "not the official app" screen. Treat every other download link with
suspicion.

## Reporting a fake or copied app

Open an issue or contact the developer through the Telegram link in the app's
Help & Support screen with the store link and screenshots. Copies that break the
GPL (no source, removed credits) or that misuse the branding can be reported to
the store or hosting provider (Google Play, GitHub DMCA, and so on).
